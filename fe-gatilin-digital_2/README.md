## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Colores
Plumaje Digital

Fucsia / Magenta (Principal): #FF007F (Representa las plumas más altas).

Amarillo Solar (Acento): #FFEB3B (El brillo de los bordados y plumas amarillas).

Turquesa / Cian (Contraste): #00E5FF (Muy común en las cintas y pañuelos, contrasta genial con el fucsia).

Blanco Puro: #FFFFFF (Para el texto o fondos limpios).



Máscara y Elegancia

Negro Azabache (Fondo/Base): #121212 (La piel de la máscara).

Dorado / Ocre (Principal): #FFC107 (Los bordados de los cotones).

Rojo Carmesí (Acento): #D32F2F (Los labios de la máscara y los pantalones).

Plata / Gris Claro: #E0E0E0 (Detalles metálicos).



Textil Andino

Azul Añil / Rey (Principal): #2962FF (Muchos cotones/chaquetas son de este azul intenso).

Naranja Atardecer (Acento): #FF9800 (Complementario perfecto para el azul, presente en flores y detalles).

Verde Esmeralda: #00C853 (Representa la naturaleza y cintas verdes).

Crema / Hueso: #F5F5F5 (Para suavizar, en lugar de blanco puro).

Verde Bosque Profundo: #1B5E20 (Crea un contraste clásico y natural. Ideal para bordes o sombras duras.).
